# ADR-005：ASR 后端抽象

- 状态：暂定
- 日期：2026-09-29

## 决策

定义统一 `ASRBackend` 接口，候选后端为 macOS MLX Whisper 和 whisper.cpp（Metal/Vulkan）；云端转写只作为显式可选项。模型默认为 large-v3-turbo。允许用户为每段指定 `auto|zh|en|de` 语言 hint。

## 证据与限制

M5 合成单语短句基准中两种本地后端都达到低于音频时长的处理时间，固定语言识别正确。模型量化不同且没有真实混说样本，尚不足以确定统一默认后端或真实准确率。

## 后果

保留后端配置和测量能力；在自录混说样本和 Linux 设备验证后再确定跨平台默认选择。中文简繁规范化作为输出处理步骤。
