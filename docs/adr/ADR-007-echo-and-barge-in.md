# ADR-007：回声抑制与插话检测

- 状态：待验证
- 日期：2026-09-29

## 决策

客户端在麦克风 RMS/VAD 超阈值且 Agent 正在播放时立即清空本地播放队列。macOS 和 Linux 优先使用系统回声消除；服务端 `interrupted` 事件作为同步与兜底。

## 原因

本地停播能避免等待网络往返；扬声器回声若误判为插话会造成频繁中断。

## 后果

需用耳机与扬声器分别测误触发，并验证用户插话到本地静音的延迟。Phase 0 目前仅准备 spike，尚无实测结论。

## 当前实现状态（2026-09-29）

Demo 已用近期 Agent 转写相似度过滤本地 Whisper 与 Live 输入中的文字回声副本，并将 Agent 自身回答保存在同一份逐字稿中。可选 `pywebrtc-audio` extra 已接入 WebRTC AEC3；输出回调生成 16 kHz 扬声器参考帧，输入回调处理后再送本地识别、Live 和 RMS 插话检测。原始麦克风 WAV 不做 DSP 修改。参考帧目前按 FIFO 缓冲并用 `stream_delay_ms` 提供 20 ms 初始估计；这不是已校准的硬件时间戳同步。M5 MacBook Air 麦克风/扬声器低电平参考检查中，20–35 ms 在多数窗口优于 50 ms；真实语音、不同音量和长时稳定性仍待验证。
