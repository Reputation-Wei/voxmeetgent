# ADR-004：介入策略可配置

- 状态：已接受
- 日期：2026-09-29

## 决策

实现 `silent`、`on_request` 和 `proactive` 三种介入模式，默认 `on_request`。实时主模式可以持续向 Live 发送会议音频以保持上下文，但所有策略都必须经过明确呼叫门控；默认仅当转写中出现“Agent，你怎么看？”或英文/德文对应短语时允许播报。仅提及 Agent、普通提问或 fact check 关键词均不授权语音。

## 原因

会议助手可能打断讨论；是否发声需要清晰且可控的策略。

## 后果

模型可以生成音频，但播放前由应用策略决定是否送至扬声器。低置信度结论使用谨慎措辞，并提供依据。

## 用户约束（2026-09-29）

用户指定只有明确呼叫“Agent，你怎么看？”时 Agent 才能说话。因此 `proactive` 只能影响被呼叫后的回复方式，不能开启无人呼叫时的主动播报；播放队列必须有该呼叫的单回合授权。
